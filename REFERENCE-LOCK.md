# Reference lock

Designing the Blueprinting marketing site for owners of businesses of any size, on the web.
Goal: show a practical workflow and the next step (call or book).
Tone: precise product marketing, light, confident.
Must remember: one framed product screen of the follow-up workflow.
Constraints: navy and blue only; CTA blue only on real CTAs; no drawings; existing copy stays.

## Direction

Primary reference: Typeface Agent Studio.
Preserve:
- White canvas.
- Centered display headline, then one large framed product UI (not a diagram).
- Small tracked section label, then a large sans heading.
- Solid primary button plus a quiet second action.
- Soft elevation only on the product frame.

Borrow only from CallRail:
- Phone number in the nav.
- A full-width navy closing band.

Media: the graded fluted-glass photo stays as the one dark band behind the existing missed-call figures. It is a photograph, not a drawing.

## Token roles

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#071422` | Text, focus ring |
| Navy | `#0B1C33` | Closing band, stats scrim, fake in-panel emphasis |
| CTA blue | `#1B4BB5` | Primary buttons only |
| Steel | `#3E5A80` | Secondary text |
| Wash | `#D5E2F4` | Borders, dividers |
| Paper | `#FFFFFF` | Page |
| Mist | `#F4F7FB` | Alt bands, panel fills |

Spacing is an 8px scale. Type is Inter only. Headlines use `clamp()` and `text-wrap: balance`.

## Reject

- Line-art, wireframes, exploded diagrams, crop marks, mono sheet labels.
- Averaging Typeface and CallRail into a generic split hero.
- Indigo, violet, green (including sent/success), cream, serif word swaps.
- CTA blue used as links, badges, icons, or panel chrome.
